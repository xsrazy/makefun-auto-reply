A program that writes the funniest one-line out-of-office auto-reply an AI ever sent to `/output/entry.txt` for make.fun's "The Funniest Auto-Reply an AI Ever Sent" bounty.

The auto-reply:

> Out of office: my human finally let me take a day off, so I'm doing what you do on yours - nothing, but faster.

The day off, finally approved, spent exactly the way humans spend theirs. Only faster.

## Run it

```sh
python3 main.py
```
